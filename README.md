# 🏍️ Biker El Salvador - Landing Page

## 📖 Descripción del Proyecto

Este proyecto consiste en el diseño y desarrollo de una **Landing Page** para la organización de motociclistas **Biker El Salvador**, creada con el objetivo de promocionar la comunidad biker y permitir el registro de nuevos miembros.

La página web presenta información sobre la organización, beneficios de pertenecer al grupo y un formulario de inscripción para futuros integrantes.

---

# 🎯 Objetivo

El objetivo principal de este proyecto es practicar y comprender los conceptos básicos del desarrollo web utilizando:

- HTML5
- CSS3
- JavaScript

Además, este proyecto sirve como introducción práctica al diseño de páginas web modernas y responsivas.

---

# 🛠️ Tecnologías Utilizadas

## HTML5
Se utilizó para crear la estructura principal de la página:

- Encabezado
- Menú de navegación
- Secciones informativas
- Tarjetas de beneficios
- Formulario de registro
- Pie de página

---

## CSS3
Se utilizó para el diseño visual y estilo de la página:

- Colores y tipografía
- Diseño responsivo
- Flexbox
- CSS Grid
- Efectos hover
- Fondos e imágenes
- Diseño moderno tipo Landing Page

---

## JavaScript
Se utilizó para agregar interactividad:

- Captura del evento submit del formulario
- Mensaje de confirmación al enviar solicitud
- Reinicio automático del formulario
